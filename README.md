
# Lista de Exercícios Python

Este repositório contem uma seleção de 50 exercícios já resolvidos estruturados usados para praticar, aprofundar e consolidar habilidades em Python — desde os fundamentos até conceitos intermediários.

## Features

- Controle de fluxo: if/elif/else, laços for/while, break, continue

- Estruturas de dados: listas, matrizes 3x3, dicionários, conjuntos (set), list comprehensions

- Manipulação de String: f-strings, slicing ([::-1]), métodos de string (split, strip, isdigit, isalpha)

- Funções e algoritmos: funções com type hints, recursão, atribuição múltipla (x, y = y, z)

- Tratamento de erros: blocos try/except ValueError

- Funções built-in: sum, len, max, min, zip, sorted, filter, range, dict.fromkeys

- Módulos padrão: math (pi, factorial), random (randint, choices, sample, uniform), string

- Visualização de dados: matplotlib.pyplot (subplots, gráficos de barras em grayscale)
